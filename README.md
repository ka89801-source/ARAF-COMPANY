# أعراف للأعمال — بوابة المنشآت (نظام الفخامة الهادئة)

نسخة B2B من منصة أعراف، مبنية على نظام تصميم **Quiet Luxury**: كحلي + ذهبي فقط، مساحات سخية، حركة منضبطة، وميزان عدالة خطي ذهبي كتوقيع بصري. باقات شهرية وتفعيل **يدوي** بالكامل.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة التسويقية — مكتفية بذاتها (رأس داكن، شريط عائم، باقات، طلب انضمام) |
| `login.html` | دخول المنشآت — مكتفية بذاتها |
| `platform.html` | بوابة المنشأة — مكتفية بذاتها (شاشة ترحيب، رصيد، طلبات، باقة) |
| `accounts.js` | **مركز التحكم اليدوي** — الحسابات والباقات والمحامين ورقم الواتساب |
| `terms.html` | الشروط والأحكام |

## قبل النشر — خطوة إلزامية

في `accounts.js`:
1. راجع `ARAF_BIZ_WHATSAPP` الخاص بفريق أعراف (بصيغة دولية بدون +)
2. عدّل أرقام جوال المحامين في حقل `manager` لكل حساب
3. عند تجهيز الداش بورد، ضع رابط Supabase Edge Function أو API في `ARAF_BIZ_REQUESTS_ENDPOINT`

> طلبات الخدمات لا تُرسل عبر واتساب. تُحفظ فوراً في «طلبات منشأتي»، وعند ضبط `ARAF_BIZ_REQUESTS_ENDPOINT` تُرسل إلى الداش بورد بصيغة JSON. لا تضع مفتاح `service_role` أو أي سر داخل ملفات الواجهة العامة.

## تفعيل شركة جديدة (يدوياً)

أضف كائناً في `ARAF_BIZ_ACCOUNTS` داخل `accounts.js`:

```js
{
  code: 'ARF-1004',            // رمز تسلّمه للعميل
  pin: '123456',               // الرقم السري (6 أرقام)
  name: 'شركة النخبة للتجارة',
  type: 'شركة',                // شركة | مؤسسة | جمعية
  plan: 'imad',                // sanad | imad | diwan
  start: '2026-08-11',
  used: { consult: 0, contracts: 0, letters: 0, najiz: 0, violations: 0, governance: 0, memos: 0, risk_review: 0, negotiation: 0 },
  manager: {
    name: 'أ. فلان الفلاني',
    title: 'محامٍ مرخص — مدير حساب منشأتكم',
    phone: '9665XXXXXXXX',
    hours: 'الأحد – الخميس، 9ص – 5م'
  }
}
```

ثم انشر على Vercel وسلّم العميل الرمز والرقم السري.

## تحديث استهلاك الباقة

بعد تنفيذ كل خدمة، ارفع العدّاد المقابل في `used` وانشر — يرى العميل رصيده محدثاً فوراً.

## الباقات

| الباقة | السعر | أبرز النطاق الشهري |
|---|---:|---|
| **سند** | 500 ر.س | 3 استشارات، عقدان، خطابان أو إنذاران، طلبان عبر ناجز، اعتراض حكومي واحد، وخصم 10% على القضايا |
| **عماد** | 2,500 ر.س | 10 استشارات، 5 عقود، 5 خطابات أو إنذارات، 5 طلبات ناجز، 3 اعتراضات حكومية، 3 أعمال حوكمة، مدير حساب، وخصم 15% |
| **ديوان** | 5,000 ر.س | استشارات بلا حد، 10 عقود، 10 خطابات أو إنذارات، 10 طلبات ناجز، 6 اعتراضات، 3 مذكرات، 6 أعمال حوكمة، مراجعة شهرية، اجتماع تفاوضي، مستشار مخصص، وخصم 20% |

التعديل من `ARAF_PLANS` في `accounts.js`.

> الاعتراض المشمول هو إعداد الاعتراض ورفعه إلكترونيًا أمام الجهة الحكومية، ولا يشمل دعوى أمام المحكمة الإدارية أو الحضور أمام اللجان. كما لا تشمل الباقات استلام القضايا أو الترافع أو حضور الجلسات أو الرسوم الحكومية.
