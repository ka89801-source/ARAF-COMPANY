# أعراف للأعمال — بوابة المنشآت

نسخة B2B من منصة أعراف، مخصصة للشركات والمؤسسات، بنموذج **باقات شهرية** وتفعيل **يدوي** بالكامل من فريق أعراف.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة التسويقية: الباقات الثلاث + نموذج طلب الانضمام (يُرسل عبر واتساب) |
| `login.html` | دخول المنشآت برمز المنشأة + الرقم السري |
| `platform.html` | بوابة المنشأة: شاشة الترحيب، لوحة الرصيد، طلب الخدمات، سجل الطلبات، تفاصيل الباقة |
| `biz.css` / `biz.js` | أنماط ومنطق البوابة |
| `accounts.js` | **مركز التحكم اليدوي** — الحسابات والباقات ورقم الواتساب |
| `terms.html` | الشروط والأحكام |

## قبل النشر — خطوة إلزامية

في `accounts.js` عدّل رقم الواتساب:

```js
window.ARAF_BIZ_WHATSAPP = '9665XXXXXXXX'; // ضع رقم فريق أعراف بدون +
```

## تفعيل شركة جديدة (يدوياً)

1. افتح `accounts.js`
2. أضف كائناً جديداً في `ARAF_BIZ_ACCOUNTS`:

```js
{
  code: 'ARF-1004',            // رمز تسلّمه للعميل
  pin: '123456',               // الرقم السري (6 أرقام)
  name: 'شركة النخبة للتجارة', // كما سيظهر في الترحيب
  type: 'شركة',                // شركة | مؤسسة | جمعية
  plan: 'imad',                // sanad | imad | diwan
  start: '2026-08-11',         // بداية الاشتراك (لحساب دورة التجديد)
  used: { consult: 0, contracts: 0, letters: 0, najiz: 0, memos: 0 }
}
```

3. انشر التعديل على Vercel، ثم أرسل للعميل الرمز والرقم السري.

## تحديث استهلاك الباقة

بعد تنفيذ كل خدمة، ارفع العدّاد المقابل في `used` للحساب المعني وانشر — سيرى العميل رصيده محدثاً فوراً.

## الباقات

| الباقة | السعر | الفكرة |
|---|---|---|
| **سند** | 1,500 ر.س | الغطاء الأساسي للمنشآت الناشئة |
| **عماد** | 3,500 ر.س | الركيزة الشهرية للشركات النامية (الأكثر اختياراً) |
| **ديوان** | 7,500 ر.س | إدارة قانونية متكاملة — ديوان محاماة داخلي |

تعديل الحدود والأسعار والمزايا كله من `ARAF_PLANS` في `accounts.js`.

## ملاحظات

- الطلبات تصل عبر **واتساب** برسالة جاهزة تتضمن اسم المنشأة ورمزها وباقتها.
- سجل "طلبات منشأتي" محلي على جهاز العميل (localStorage) — المرجع الرسمي هو رسائل واتساب.
- شاشة الترحيب تعرض نسخة كاملة عند الدخول الأول، ونسخة أسرع عند الزيارات اللاحقة.
- حسابات تجريبية جاهزة: `ARF-1001 / 112233` (عماد)، `ARF-1002 / 445566` (سند)، `ARF-1003 / 778899` (ديوان).

## النشر على Vercel

المشروع ثابت بالكامل (لا API) — ارفع المجلد كما هو إلى GitHub واربطه بـ Vercel دون أي إعدادات إضافية.
