# أعراف للأعمال — بوابة المنشآت

نسخة الإنتاج متعددة الملفات، بعد تطبيق تصميم «الفخامة الهادئة» على المشروع الحالي دون دمجه في ملف تجريبي واحد.

## الملفات
- `index.html`: الصفحة التسويقية وطلب الانضمام.
- `login.html`: دخول المنشآت.
- `platform.html`: بوابة المنشأة وشاشة الترحيب.
- `biz.css`: تصميم البوابة.
- `biz.js`: منطق البوابة والطلبات والتواصل.
- `accounts.js`: الباقات والحسابات ورقم واتساب الفريق.
- `terms.html`: الشروط والأحكام.
- `logo.png`: شعار أعراف.

> ملاحظة: الحسابات ما زالت تعمل بالنظام اليدوي الحالي داخل `accounts.js`، وسجل الطلبات ما زال يعتمد على `localStorage` إلى حين ربط المشروع بقاعدة بيانات حقيقية.
